# Coffee Sales Dashboard

## Overview

The Coffee Sales Dashboard is a business intelligence and data visualization project developed using **Microsoft Excel** to analyze coffee sales performance, customer purchasing behavior, and product trends.

The dashboard transforms raw sales data into interactive visual insights that help businesses monitor revenue, identify top-performing products, track customer trends, and support data-driven decision-making.

---

## Project File

### `Coffee Sales Dashboard.xlsx`

Excel dashboard containing:

* Interactive sales visualizations
* KPI cards
* Product performance analysis
* Customer insights
* Time-based sales trends
* Dynamic filters and slicers

---

The main objective of this project is to:
